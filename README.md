## Briaton

В данном проекте я реализовал интерактивный функционал для приложения используя чистый **JS**, валидацию формы с помощью библиотеки **Just-validate**. Также интегрировал слайдер в блоке товар дня с помощью библиотеки **Swiper.js**

### Описание функционала

Как только вы откроете приложение, вам откроется сайт. На нем будут представлены каталог магазина, продающего светильники. Вы сможете выбрать в header город, в котором вы находитесь, и открыть бургерное меню, нажав на  кнопку 'каталог'. Эти товары Вы сможете добавить в корзину и убирать из неё, отфильтровать по категориям светильников, по статусу (все/в наличии), отсортировать по цене или популярности. На сайте присутствует пагинация. Также есть блок товаров дня, реализованный в виде слайдера с помощью *Swiper.js*. Ниже в блоке "Ответы на частые вопросы от покупателей" выполнен функционал аккордеона. Также добавлена валидация формы для блока "Сложно выбрать? Отбратитесь к нам и мы поможем" с помощью *Just-validate*.

### Запуск приложения

Для того, чтобы запустить проект надо перейти в проект и нажать правой кнопкой мыши на фаил 'catalog.html' и в выпавшем меню выбрать 'Open with Live Server' ('Открыть с помощью Live Server'). Если у вас нет данного расширения, его надо предварительно установить.

Ссылка на расширение **Live Server**: https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer
