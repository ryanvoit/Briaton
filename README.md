## Briaton

В данном проекте я реализовал интерактивный функционал для приложения используя чистый **JS**, валидацию формы с помощью библиотеки **Just-validate**. Также интегрировал слайдер в блоке товар дня с помощью библиотеки **Swiper.js**

### Запуск приложения
Для того, чтобы запустить проект надо перейти в проект и нажать правой кнопкой мыши на фаил 'catalog.html' и в выпавшем меню выбрать 'Open with Live Server' ('Открыть с помощью Live Server'). Если у вас нет данного расширения, его надо предварительно установить.

Ссылка на расширение **Live Server**: https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer
